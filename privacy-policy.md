# ViewLift Helper Privacy Policy

**Last updated: August 9, 2026**

ViewLift Helper is a productivity extension for ViewLift support workflows. It works with the Better ViewLift userscript to capture the visible ViewLift CMS tab when the user explicitly requests a screenshot.

## Data handled

The extension may temporarily handle visible website content, including names, email addresses, ticket identifiers, and other information displayed in the ViewLift CMS. This content is used only to create the requested screenshot and pass it to the Better ViewLift userscript for the user's Freshdesk workflow.

## Collection and sharing

ViewLift Helper does not sell, advertise against, or transmit captured content to the extension developer or external servers. The extension does not collect browsing history, passwords, authentication codes, location, or payment information. Captured screenshots remain under the user's control in the browser, clipboard, or approved internal support workflow.

## Security and retention

The extension does not maintain a remote database or user profile. Users can stop capture by disabling or removing the extension. The ViewLift Helper source code is published in the project repository.
